## About

This repository is a demo for Homework 1 of TFCB 2026, showing how to use GitHub issues, Markdown logs, and commits to document a molecular biology experiment.

Made by Alessandro Rizzi assisted by Claude

**Folder layout:**

- `README.md` — this file
- `experiments/` — experiment logs in Markdown
  - `2026-10-13_i1_SMARTer TCR Library Generation.md` — log for issue 1
  - `img/` — images referenced by the logs
- `analysis/qpcr/2026-10-14_i2_tidy_data_exercise/` — tidy-data exercise for issue 2
  - `README.md` — what was done and how
